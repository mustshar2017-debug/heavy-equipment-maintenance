# heavy-equipment-maintenance
Heavy Equipment Maintenance App – Offline fault codes database, diagnostics, repair guides, spare parts and maintenance records.


## تحديث قاعدة أكواد فولفو

- إضافة قاعدة مرجعية مستخرجة من قائمة SINOCMP المؤرخة 12 فبراير 2022.
- تتضمن 96 مدخلاً بصيغة MID/PID/PPID/SID/FMI و90 رمز فولفو داخلياً، مع فصل الأوصاف التفصيلية المتاحة عن الإدخالات المرجعية المختصرة.
- البحث يقبل الصيغ المعروضة على شاشة الحفار، وكذلك رموز فولفو الداخلية مثل ER32-03.
- تُنسخ ملفات البيانات إلى مجلد `www` ضمن بناء GitHub Pages وتُدرج قاعدة الأكواد الجديدة في التخزين المؤقت للعمل دون اتصال.
- يجب مطابقة كل كود مع طراز الحفار ورقمه التسلسلي ودليل الخدمة قبل تنفيذ الإصلاح.
